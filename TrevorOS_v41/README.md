# TrevorOS v4.1

TrevorOS v4.1 is a structured second-brain workspace that combines repeatable project operations, personal knowledge management,
 and reliable logging. Use the ontology to label every record consistently, and validate captured JSON with `schema.json` before
 storage so entries stay interoperable across logs, reflections, actions, projects, and long-lived knowledge.

## Templates
- `templates/daily_log_template.md`: start a daily note with schema-aligned metadata and Edge Coach v2 prompts.
- `templates/edge_coach_template.md`: drop-in Edge Coach v2 reflection block for any note.
- `templates/capture_template.json`: blank, schema-valid record for programmatic capture.
